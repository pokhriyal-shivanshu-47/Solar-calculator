# Solar-calculator
Description:
A clean and responsive web-based Solar Calculator built for the Direct Watts IT Internship Program.
This tool helps new users easily estimate their ideal solar system size, number of panels, and approximate system cost — without any technical knowledge.
Built using HTML, CSS, and JavaScript, the project focuses on user experience, modern design, and practical solar estimation logic.

Features:
Calculates estimated system size (in kW)
Estimates number of solar panels (based on 350W default)
Shows approximate total system cost
Displays potential monthly savings
Includes an informative section about solar energy & its benefits
Fully responsive design (works on desktop & mobile)
Modern dark navy-blue theme with smooth animations
Built by Direct Watts Interns

Tech Stack:
Frontend: HTML, CSS, JavaScript
Design: Responsive Flexbox layout, modern UI/UX styling
